Level 1

Novice: Basics of PCB Design

Objective

Build a strong foundation in PCB fundamentals and EDA tool navigation.

Key Learning Areas

  • Introduction to PCB technology, types, and applications.
  • Electronic components overview (active, passive, electromechanical).
  • Schematic creation using industry-standard EDA software.
  • Understanding nets, symbols, and footprints.
  • Basic design rules and standards (IPC introduction).
  • Single-layer PCB layout creation.
  • Basic routing techniques and copper pours.
  • Generating Gerber files for fabrication.

Outcome

By the end of Level 1, learners can design and generate files for a simple, single-layer PCB ready for manufacturing.
